# Install TMRs Ctrl Msg · ఇన్‌స్టాల్ · इंस्टॉल

App link / యాప్ లింక్ / ऐप लिंक: `https://<your-username>.github.io/<repo-name>/`

## English
**Android (Chrome)**
1. Open the app link in **Chrome**.
2. Tap **⋮ menu → Install app** (or **Add to Home screen**).
3. Open the app once **with internet** and wait a few seconds. Now it works **offline**.

**iPhone (Safari):** open the link → **Share → Add to Home Screen**.

**Update:** open the app once with internet now and then. The new version loads the next time you open it. If the app looks old, close it fully and open again.

**Remove:** long-press the icon → Uninstall. This deletes your saved data. Take **Backup now** first.

## తెలుగు
**Android (Chrome)**
1. యాప్ లింక్‌ను **Chrome** లో తెరవండి.
2. **⋮ మెనూ → Install app** (లేదా **Add to Home screen**) తాకండి.
3. యాప్‌ను ఒకసారి **ఇంటర్నెట్‌తో** తెరిచి కొన్ని సెకన్లు ఆగండి. ఇప్పుడు ఇది **ఆఫ్‌లైన్‌లో** పనిచేస్తుంది.

**iPhone (Safari):** లింక్ తెరవండి → **Share → Add to Home Screen**.

**అప్‌డేట్:** అప్పుడప్పుడు ఇంటర్నెట్‌తో యాప్ తెరవండి. కొత్త వెర్షన్ తరువాతిసారి తెరిచినప్పుడు వస్తుంది. పాతదిలాగే కనిపిస్తే యాప్‌ను పూర్తిగా మూసి మళ్ళీ తెరవండి.

**తొలగించడం:** ఐకాన్‌ను నొక్కి ఉంచి Uninstall చేయండి. దీనివల్ల సేవ్ చేసిన డేటా పోతుంది. ముందు **Backup now** తీసుకోండి.

## हिन्दी
**Android (Chrome)**
1. ऐप का लिंक **Chrome** में खोलें।
2. **⋮ मेन्यू → Install app** (या **Add to Home screen**) दबाएँ।
3. ऐप को एक बार **इंटरनेट के साथ** खोलकर कुछ सेकंड रुकें। अब यह **ऑफ़लाइन** चलेगा।

**iPhone (Safari):** लिंक खोलें → **Share → Add to Home Screen**।

**अपडेट:** बीच-बीच में इंटरनेट के साथ ऐप खोलें। नया संस्करण अगली बार खोलने पर आता है। पुराना ही दिखे तो ऐप पूरी तरह बंद करके फिर खोलें।

**हटाना:** आइकन को दबाए रखकर Uninstall करें। इससे सहेजा डेटा मिट जाता है। पहले **Backup now** लें।
